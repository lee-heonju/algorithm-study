## 📁 폴더 구조
```
algorithm-study/
├── 01_구현/
│   └── 문제번호_문제이름.cpp
├── 02_그리디/
├── 03_DFS_BFS/
├── 04_DP/
├── 05_그래프/
└── README.md
```
> **DFS/BFS**: 그래프나 트리를 탐색하는 대표적인 두 가지 방식 (깊이 우선 / 너비 우선)
> **DP(Dynamic Programming, 동적 계획법)**: 큰 문제를 작은 문제로 쪼개 그 결과를 저장해가며 푸는 방식
>
> 폴더는 알고리즘 유형(카테고리)별로 분류하고, 새 유형이 생기면 폴더를 추가합니다.
